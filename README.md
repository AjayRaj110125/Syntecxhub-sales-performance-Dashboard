# Syntecxhub-sales-performance-Dashboard
An interactive Power BI dashboard that analyzes sales performance using key business metrics such as total sales, profit, orders, regional performance, and product trends. Built with Power BI, Power Query, DAX, and Excel to deliver actionable business insights through dynamic visualizations.
# Sales Performance Dashboard (Power BI)

## Project Overview
This Power BI dashboard analyzes company sales performance using interactive visualizations. It helps businesses monitor revenue, profit, customer trends, and regional performance.

## Objectives
- Analyze total sales
- Monitor monthly sales trends
- Compare regional performance
- Identify top-selling products
- Evaluate profit margins

## Dataset
- Sales_Data.xlsx
- 10,000+ records
- Includes Orders, Customers, Products, Regions, Profit, Quantity, Discounts

## Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX

## Dashboard Features
- KPI Cards
- Sales Trend
- Profit Analysis
- Category-wise Sales
- Region-wise Sales
- Top Customers
- Top Products
- Interactive Filters

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Average Order Value

## Business Insights
- West region generated the highest revenue.
- Technology category achieved the highest profit.
- Sales peaked during November and December.
- Office Supplies had the largest number of orders.
- Discounts above 20% reduced profit significantly.
